ANDROID APK BUILD GUIDE — India In-Time
==========================================
Turn your web app into a real Android APK using TWA (Trusted Web Activity)
This creates a REAL Android app — not just a browser shortcut!

══════════════════════════════════════════
METHOD 1 — EASIEST: PWABuilder (Free, 5 min)
══════════════════════════════════════════

STEP 1 — First deploy your app online (required for APK)
  → See DEPLOY_GUIDE.txt for how to deploy to Railway + Vercel

STEP 2 — Go to https://www.pwabuilder.com
  → Enter your app URL (e.g. https://india-in-time.vercel.app)
  → Click "Start"

STEP 3 — PWABuilder will analyze your app
  → It should show green checkmarks for Manifest ✅ and Service Worker ✅
  → Click "Package For Stores"

STEP 4 — Select Android
  → Click "Android" → "Generate Package"
  → Fill in:
    - App name: India In-Time
    - Package ID: com.indiaInTime.app
    - Version: 1.0.0
  → Click "Generate"

STEP 5 — Download the APK
  → Click "Download" → you'll get a .apk file
  → Send it to your Android phone
  → On your phone: Settings → Install unknown apps → Allow
  → Tap the .apk file to install!

══════════════════════════════════════════
METHOD 2 — ADVANCED: Android Studio (Full control)
══════════════════════════════════════════

Requirements:
- Android Studio (free): https://developer.android.com/studio
- Java JDK 17: https://adoptium.net
- Your app must be deployed online first

STEP 1 — Install Android Studio
  → Download and install (takes ~10 min)
  → Open Android Studio → New Project → Empty Activity

STEP 2 — Add TWA dependency
  In app/build.gradle, add:
  
  dependencies {
    implementation 'com.google.androidbrowserhelper:androidbrowserhelper:2.5.0'
  }

STEP 3 — Configure AndroidManifest.xml
  Add this inside <application>:
  
  <activity android:name="com.google.androidbrowserhelper.trusted.LauncherActivity">
    <meta-data
      android:name="android.support.customtabs.trusted.DEFAULT_URL"
      android:value="https://your-app-url.com" />
    <intent-filter android:autoVerify="true">
      <action android:name="android.intent.action.VIEW"/>
      <category android:name="android.intent.category.DEFAULT"/>
      <category android:name="android.intent.category.BROWSABLE"/>
      <data android:scheme="https" android:host="your-app-url.com"/>
    </intent-filter>
  </activity>

STEP 4 — Build APK
  → Build → Generate Signed Bundle / APK
  → Select APK → Create new keystore
  → Fill in keystore details → Next → Release → Finish
  → APK saved to app/release/app-release.apk

STEP 5 — Install on phone
  → Connect phone via USB
  → Enable Developer Options (tap Build Number 7 times)
  → Enable USB Debugging
  → adb install app-release.apk

══════════════════════════════════════════
METHOD 3 — PUBLISH TO GOOGLE PLAY STORE
══════════════════════════════════════════

Requirements:
- Google Play Developer Account ($25 one-time fee)
- Signed APK or AAB from Method 2

STEP 1 — Go to https://play.google.com/console
STEP 2 — Create new app → India In-Time
STEP 3 — Fill in store listing:
  - Description: AI-powered India travel companion
  - Category: Travel & Local
  - Screenshots: Take screenshots from your phone
STEP 4 — Upload your signed .aab file
STEP 5 — Set pricing: Free
STEP 6 — Submit for review (takes 3-7 days)

══════════════════════════════════════════
RECOMMENDED ORDER:
══════════════════════════════════════════
1. First: Deploy online (Railway + Vercel) — see DEPLOY_GUIDE.txt
2. Then: Install as PWA on your phone (tap Install button in app)
3. Then: Use PWABuilder to generate APK
4. Later: Publish to Play Store when ready

Note: The PWA install (tap the "Install" button in the app header)
already gives you an app icon on your home screen that works
EXACTLY like a native app — no APK needed for personal use!
