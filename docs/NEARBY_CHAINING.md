# Nearby place chaining

Itineraries balance:

1. **Time intelligence** — best hours / phases (sunrise, lunch, golden hour, dinner)
2. **Weather & crowd** — visit score components
3. **Scenic windows** — sunrise/sunset viewpoints
4. **Nearby chaining** — next stop prefers places within ~1.5–3.5 km of the current one

Example: **Yarada Beach → Dolphin’s Nose Lighthouse** (same cluster) instead of jumping across the city to an unrelated stop.

Long hops (>18 km) are skipped when a local plan is already underway.
