# Time Intelligence Benchmark — v3.7 vs v3.8

This benchmark compares the v3.7 ranking model with the v3.8 robust multi-objective decision model using identical deterministic synthetic scenarios. It measures ranking regret against an independent synthetic oracle, temporal alignment, route cost, robustness, and future-opportunity behavior.

It is **not** evidence of real-world accuracy. Real validation requires replaying anonymized historical trips and measuring observed outcomes.

Run:

```bash
npm run benchmark:time-intelligence
```
