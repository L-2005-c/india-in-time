## 1. SaaS Tiers, Token Allocations & Quota Enforcement

India In Time enforces multi-tier API rate limiting and token metering across all AI, Routing, and Time Intelligence endpoints.

| Tier | Monthly Fee | Gemini AI Quota | Time Intelligence QPS | OSRM Routing Cache TTL | Offline Travel Pass | Support SLA |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **Explorer (Free / Guest)** | ₹0 | 50 credits / session | 10 req/min | 24 Hours | 3 Passes / month | Community |
| **Nomad (Pro)** | ₹499 / mo | 500 requests / day | 60 req/min | 7 Days | Unlimited | 24h Email |
| **Enterprise / Tour Ops** | ₹4,999 / mo | 10,000 requests / day | 300 req/min | Dedicated Tile Cache | White-label PDF & Web | 1h Dedicated |

### 1.1 Quota Enforcement Architecture
- **In-Memory Token Bucket + Redis Cluster**: Local per-process rate limiting via `express-rate-limit` with optional Redis fallback via `REDIS_URL`.
- **Circuit Breaker Integration**: If Gemini API returns 429 or 503, `services/gemini.js` opens the circuit breaker, and responses degrade gracefully to cached or heuristic seasonal advice without throwing 500 errors.

## 2. Spatial Indexing Roadmap (R-Tree & PostGIS)

Currently, geospatial proximity clustering operates using great-circle Haversine calculations (`hvKm`) in `services/travelIntelligence/proximityClustering.js` and `frontend/app-src/src/utils/geo.js` ($O(N \log N)$ complexity).

### 2.1 Scale Roadmap ($>100,000$ Places)
1. **SQLite R\*Tree Virtual Table (`db/places_spatial.sqlite`)**:
   ```sql
   CREATE VIRTUAL TABLE places_rtree USING rtree(
       id,
       minX, maxX, -- Min/Max Longitude (68.0 to 98.0)
       minY, maxY  -- Min/Max Latitude (6.0 to 38.0)
   );
   ```
2. **PostgreSQL / PostGIS GiST Spatial Indexing**:
   ```sql
   CREATE EXTENSION IF NOT EXISTS postgis;
   ALTER TABLE places ADD COLUMN geom geometry(Point, 4326);
   UPDATE places SET geom = ST_SetSRID(ST_MakePoint(lon, lat), 4326);
   CREATE INDEX idx_places_spatial_gist ON places USING GIST (geom);
   ```
3. **K-Nearest Neighbors ($k$-NN) Query Performance**:
   ```sql
   SELECT id, name, ST_Distance(geom, ST_SetSRID(ST_MakePoint($1, $2), 4326)::geography) / 1000 AS distance_km
   FROM places
   ORDER BY geom <-> ST_SetSRID(ST_MakePoint($1, $2), 4326)
   LIMIT 10;
   ```
   - Query execution time drops from $\sim 15\text{ ms}$ to $<0.8\text{ ms}$ for $100\text{k}+$ destinations.

## 3. Database Backup & Restore Integrity Standard

All database backups generated by `scripts/backup-db.js` must:
1. Include a root `manifest.json` declaring table names, row counts, creation timestamps, and individual SHA-256 file hashes.
2. Restrict export and restore targets strictly to the compile-time `ALLOWED_TABLES` allowlist.
3. Validate non-destructive dry-run restore via isolated temporary Postgres schemas (`scripts/restore-verify.js`).
