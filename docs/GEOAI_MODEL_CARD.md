# GeoAI Model Card

## Scope
India In-Time uses deterministic geospatial/time rules plus historical/user-feedback-derived crowd models.

## Data provenance
Every model feature must be traceable to a source class: observed, forecast, historical, predicted, estimated, or unavailable.

## Minimum training record
Training runs should record model version, sample count, feature availability, evaluation date, and fallback reason.

## Confidence
Confidence is evidence-driven. It must decrease when critical sources are missing, stale, conflicting, or under-sampled.

## Limitations
Source code alone cannot prove provenance, dataset licensing, field collection procedures, or statistical calibration. Those require operational evidence and dataset/version records.
